Deploy an open source, distributed JSON document on a NoSQL database cluster.

This content showcases Couchbase's Cluster Operator solution deployed on Red Hat® OpenShift® Container Platform. Couchbase Cluster exposes a scale-out, key-value store with a managed cache for sub-millisecond data operations. It also has purpose-built indexers for efficient queries and a powerful query engine for executing SQL-like queries.

The included assets automatically provision the Couchbase Operator on OpenShift Container Platform 4.10, which you can then use in conjunction with this simple Twitter-based demo. The demo covers the following topics:

  • Creating Couchbase Secrets
  • Deploying a two-node Couchbase Cluster
  • Exposing the Couchbase Admin UI
  • Creating data buckets
  • Configuring and deploying an application which ingests content from Twitter, stores it in the cluster, and displays it dynamically using an API service.
